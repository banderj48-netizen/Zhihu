# 首版初始化策略

## 数据范围

首版只接入用户的知乎个人简介和知乎回答。知乎 OAuth、Token、原始数据读取和删除由传统后端负责，Agent 只接收经过权限过滤的证据片段。

## 审核方式

不要求用户逐项确认。初始化完成后展示一份汇总画像，用户可以整体确认、修改、跳过或重新生成。

- 整体确认后，候选画像进入用户的私有正式版本。
- 跳过确认时，候选保留为 `unconfirmed`，仍可被 Agent 使用。
- 用户拒绝或删除的内容不得进入 Agent 上下文。

## 未确认内容

`unconfirmed` 指模型根据知乎原文推断、但用户没有明确表达或确认的内容，例如由多篇回答推断出的行为倾向、兴趣强度、专业等级或人格解释。

Agent 可以使用未确认内容，但必须：

1. 在检索排序中低于已确认内容；
2. 不把它表述为用户明确事实；
3. 在回答不确定时使用“可能”“看起来”“我不太确定”等表达；
4. 不用于敏感属性推断、现实承诺或外部行动；
5. 保留对应证据引用和 `unconfirmed` 状态。

## 隐私

所有画像、原始数据、证据、记忆、测评结果和角色卡默认 `private`，默认 `share=false`。私密不影响用户自己的 Agent 使用，但禁止公开展示、跨用户召回或公共检索。

## 性格测评

性格测评不是初始化阻塞条件。用户可以跳过；跳过后人格字段保持缺失或低置信状态，Agent 依靠身份、风格、领域和行为记忆工作。

## 删除

用户撤销授权或请求删除时，传统后端必须删除所有相关原始数据、证据、索引、画像、记忆、测评、角色卡和派生缓存。Agent 收到删除事件后不得继续使用已失效内容。
