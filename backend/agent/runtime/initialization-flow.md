# Agent 初始化协作流程

传统后端完成授权、读取个人简介和回答、原始保存、清洗、证据切片和删除治理。

Agent 完成候选抽取、领域识别、观点/行为/风格分析、可选性格评测解释、三层记忆归档建议和初始化质量报告。

流程：

```text
接收授权范围内证据
→ 抽取候选画像
→ 为候选标记 source_observed 或 unconfirmed
→ 按稳定性生成深层/中层/浅层记忆建议
→ 生成初始化汇总结果
→ 接收整体确认、修改、跳过或重新生成
→ 回传确认结果和版本生成请求
```

Agent 不直接写正式画像版本。整体确认或跳过后的状态转换由传统后端执行，Agent 只回传结构化候选、证据引用、质量报告和修正提案。
