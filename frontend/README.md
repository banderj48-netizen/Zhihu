# 知交桥前端演示

## 启动

```bash
cd frontend
npm install
npm run dev
```

打开终端输出的本地地址（通常是 http://localhost:3000；若端口占用则使用 3001）。

## 小镇 Demo

首页使用 `specimen/townmap.jpg` 作为地图，并在五个建筑位置提供入口：咖啡馆、图书馆、小酒馆、戏剧院和讲座。

点击建筑后进入对应场景背景。我的看山位于左侧，可能遇见的看山位于右侧；悬停可以查看简介，点击候选看山后我的看山会移动过去并显示聊天状态。

场景背景和角色素材保存在 `public/scenes/`，页面使用本地 Mock 数据和浏览器内状态。
